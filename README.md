# YouthHub

## За проекта

YouthHub е уеб приложение, разработено с ASP.NET Core MVC, което предоставя възможност за организиране и разглеждане на младежки инициативи. Платформата позволява на потребителите да преглеждат инициативи, да ги организират по категории и да подават кандидатури за участие.

Проектът е разработен като курсов проект с цел прилагане на знания за MVC архитектурата, Entity Framework Core, релационните бази данни и уеб валидацията.

## Основни функционалности

- Преглед на младежките инициативи.
- Създаване, редактиране и изтриване на инициативи.
- Създаване и преглед на категории.
- Свързване на инициативите с категории.
- Подаване на кандидатури за инициативи.
- Преглед на подадените кандидатури.
- Клиентска и сървърна валидация на входните данни.
- Адаптивен интерфейс с Bootstrap и персонализиран CSS.

## Използвани технологии

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- Razor Views
- HTML и CSS
- Bootstrap
- JavaScript и jQuery Validation

## Архитектура

Проектът използва MVC (Model–View–Controller) архитектура.

- **Models** — описват основните обекти: инициативи, категории и кандидатури.
- **Views** — представят потребителския интерфейс чрез Razor.
- **Controllers** — обработват HTTP заявките и управляват взаимодействието между изгледите и базата данни.
- **Data** — съдържа контекста за достъп до базата данни.
- **Migrations** — съдържа миграциите за структурата на базата данни.
- **wwwroot** — съдържа CSS, JavaScript и статичните файлове.

## Изисквания

- Инсталиран .NET SDK 9.0 или съвместима версия.
- Инсталиран Microsoft SQL Server Express или друга съвместима SQL Server инстанция.
- Git.

## Стартиране на проекта

1. Клонирайте хранилището:

   ```bash
   git clone https://github.com/fysinka/YouthHub.git
   ```

2. Отворете директорията на проекта:

   ```bash
   cd YouthHub
   ```

3. Проверете връзката към SQL Server в `appsettings.json`. При необходимост променете стойността на `DefaultConnection`, така че да съответства на локалната SQL Server инстанция.

4. Възстановете зависимостите:

   ```bash
   dotnet restore
   ```

5. Приложете миграциите към базата данни:

   ```bash
   dotnet ef database update
   ```

6. Стартирайте приложението:

   ```bash
   dotnet run
   ```

7. Отворете локалния адрес, показан в терминала.

## База данни

Приложението използва Entity Framework Core за работа с Microsoft SQL Server. Връзката към базата данни се конфигурира чрез `ConnectionStrings:DefaultConnection` в `appsettings.json`.

При първоначално стартиране е необходимо миграциите да бъдат приложени към съответната база данни.
