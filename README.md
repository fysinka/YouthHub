# YouthHub

## За проекта

YouthHub е уеб приложение, разработено с ASP.NET Core MVC, което позволява на потребителите да разглеждат младежки инициативи, да ги организират по категории и да подават кандидатури за участие.

Проектът е разработен като курсов проект с цел прилагане на знания за MVC архитектурата, Entity Framework Core, релационните бази данни и валидацията на входните данни.

## Основни функционалности

- Преглед на младежките инициативи.
- Създаване, редактиране и изтриване на инициативи.
- Търсене и филтриране на инициативи.
- Организиране на инициативите по категории.
- Подаване на кандидатури за участие.
- Преглед на подадените кандидатури.
- Валидация на входните данни от страна на клиента и сървъра.
- Проверка за повторно кандидатстване с един и същ имейл за дадена инициатива.
- Адаптивен интерфейс с Bootstrap и персонализиран CSS.

## Използвани технологии

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- Razor Views
- HTML и CSS
- Bootstrap
- JavaScript и jQuery Validation

## Архитектура

Проектът използва MVC (Model–View–Controller) архитектура.

- **Models** — описват основните обекти: инициативи, категории и кандидатури.
- **Views** — представят потребителския интерфейс чрез Razor.
- **Controllers** — обработват HTTP заявките и свързват изгледите с останалата логика на приложението.
- **Services** — съдържа интерфейса и реализацията на услугата за работа с инициативи.
- **ViewModels** — съдържа моделите за формулярите и техните правила за валидация.
- **Data** — съдържа контекста за достъп до базата данни.
- **Migrations** — съдържа миграциите за структурата на базата данни.
- **wwwroot** — съдържа CSS, JavaScript и други статични файлове.

## Изисквания

- Инсталиран .NET SDK 9.0.
- Microsoft SQL Server Express или друга съвместима SQL Server инстанция.
- Git.
- Конфигурирана връзка към базата данни.

## Стартиране на проекта

1. Клонирайте хранилището:

   ```bash
   git clone https://github.com/fysinka/YouthHub.git
   ```

2. Отворете директорията на проекта:

   ```bash
   cd YouthHub
   ```

3. Проверете връзката към SQL Server в `appsettings.json`. При необходимост променете `DefaultConnection`, така че да съответства на вашата локална SQL Server инстанция.

4. Възстановете зависимостите:

   ```bash
   dotnet restore
   ```

5. Инсталирайте инструмента за миграции, ако още не е инсталиран:

   ```bash
   dotnet tool install --global dotnet-ef --version 9.0.2
   ```

6. Приложете миграциите към базата данни:

   ```bash
   dotnet ef database update
   ```

7. Стартирайте приложението:

   ```bash
   dotnet run
   ```

8. Отворете локалния адрес, показан в терминала.

## База данни

Приложението използва Entity Framework Core за работа с Microsoft SQL Server. Връзката се конфигурира чрез `ConnectionStrings:DefaultConnection` в `appsettings.json`.

При първоначално стартиране миграциите трябва да бъдат приложени към съответната база данни. Уверете се, че SQL Server е стартиран и че потребителят има необходимите права за достъп.

Не публикувайте пароли или други чувствителни данни за връзката към базата данни в публичното хранилище.
