
# YouthHub

## За проекта

YouthHub е уеб приложение, разработено с ASP.NET Core MVC, което предоставя възможност за организиране и разглеждане на младежки инициативи. Потребителите могат да преглеждат инициативи, да ги търсят, да ги филтрират по категории и да подават кандидатури за участие.

Проектът е разработен като курсов проект с цел прилагане на знания за MVC архитектурата, Entity Framework Core, релационните бази данни и уеб валидацията.

## Основни функционалности

- Преглед на младежките инициативи.
- Търсене и филтриране по категории.
- Създаване, редактиране и изтриване на инициативи.
- Управление на категории.
- Свързване на инициативи с категории.
- Подаване и преглед на кандидатури.
- Проверка за повторно кандидатстване със същия имейл за една инициатива.
- Клиентска и сървърна валидация на входните данни.
- Проверка за дата на инициативата в миналото.
- Защита от изтриване на инициатива с подадени кандидатури.
- Адаптивен интерфейс с Bootstrap и персонализиран CSS.

## Използвани технологии

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- Razor Views
- HTML и CSS
- Bootstrap
- JavaScript и jQuery Validation

## Архитектура

Проектът използва MVC (Model–View–Controller) архитектура.

- **Models** — описват инициативите, категориите и кандидатурите.
- **Views** — представят потребителския интерфейс чрез Razor.
- **Controllers** — обработват HTTP заявките.
- **Services** — съдържа услугата за работа с инициативите.
- **ViewModels** — съдържа моделите за формите и ограничава входните данни.
- **Data** — съдържа контекста за достъп до базата данни.
- **Migrations** — съдържа миграциите за структурата на базата данни.
- **wwwroot** — съдържа CSS, JavaScript и статичните файлове.

## Изисквания

- Инсталиран .NET SDK 9.0.
- Microsoft SQL Server Express или друга съвместима SQL Server инстанция.
- Git.

## Стартиране на проекта

1. Клонирайте хранилището:

   ```bash
   git clone https://github.com/fysinka/YouthHub.git
   ```

2. Отворете директорията на проекта:

   ```bash
   cd YouthHub
   ```

3. Конфигурирайте връзката към SQL Server чрез `ConnectionStrings:DefaultConnection` в `appsettings.json` или чрез подходяща локална конфигурация.

4. Възстановете зависимостите:

   ```bash
   dotnet restore
   ```

5. Инсталирайте Entity Framework Core инструмента, ако все още не е инсталиран:

   ```bash
   dotnet tool install --global dotnet-ef --version 9.0.2
   ```

6. Приложете миграциите към базата данни:

   ```bash
   dotnet ef database update
   ```

7. Стартирайте приложението:

   ```bash
   dotnet run
   ```

8. Отворете локалния адрес, показан в терминала.

## База данни

Приложението използва Entity Framework Core за работа с Microsoft SQL Server. Структурата на базата данни се управлява чрез миграции.

Преди първото стартиране трябва да бъде конфигурирана валидна връзка към SQL Server и да бъдат приложени миграциите.

Не публикувайте пароли или други чувствителни данни за връзката към базата данни в публичното хранилище.
