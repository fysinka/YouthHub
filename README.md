# YouthHub

## За проекта

YouthHub е уеб приложение, разработено с ASP.NET Core MVC, което позволява на потребителите да разглеждат младежки инициативи, да ги търсят и филтрират по категории и да подават кандидатури за участие.

Проектът е разработен като курсов проект с цел прилагане на знания за MVC архитектурата, Entity Framework Core, релационните бази данни и валидацията на входните данни.

## Основни функционалности

- Преглед на младежките инициативи.
- Търсене и филтриране на инициативи по категории.
- Създаване, редактиране и изтриване на инициативи.
- Управление на категории и свързване на инициативи с тях.
- Подаване и преглед на кандидатури.
- Проверка за повторно кандидатстване със същия имейл за една инициатива.
- Клиентска и сървърна валидация на входните данни.
- Проверка на датите при създаване и редактиране на инициативи.
- Защита от изтриване на инициатива, за която има подадени кандидатури.
- Адаптивен интерфейс с Bootstrap и персонализиран CSS.

## Структура на проекта

Проектът използва MVC (Model–View–Controller) архитектура.

- **Models** — описват основните обекти: инициативи, категории и кандидатури.
- **Views** — представят потребителския интерфейс чрез Razor.
- **Controllers** — обработват HTTP заявките и свързват изгледите с логиката на приложението.
- **Services** — съдържа интерфейса и реализацията на услугата за работа с инициативи.
- **ViewModels** — съдържа моделите за формулярите и правилата за валидация на входните данни.
- **Data** — съдържа контекста за достъп до базата данни.
- **Migrations** — съдържа миграциите за структурата на базата данни.
- **wwwroot** — съдържа CSS, JavaScript и други статични файлове.

## Изисквания

- Инсталиран .NET SDK 9.0.

- Git.
- Конфигурирана връзка към базата данни.

## Стартиране на проекта

1. Клонирайте хранилището:

   ```bash
   git clone https://github.com/fysinka/YouthHub.git
   ```

2. Отворете папката на проекта:

   ```bash
   cd YouthHub
   ```

3. Проверете връзката към SQL Server в `appsettings.json`. При необходимост променете `DefaultConnection`, така че да съответства на вашата локална SQL Server инстанция. Може да използвате и подходяща локална конфигурация.

4. Възстановете зависимостите:

   ```bash
   dotnet restore
   ```

5. Инсталирайте инструмента за миграции, ако още не е инсталиран:

   ```bash
   dotnet tool install --global dotnet-ef --version 9.0.2
   ```

6. Приложете миграциите към базата данни:

   ```bash
   dotnet ef database update
   ```

7. Стартирайте приложението:

   ```bash
   dotnet run
   ```

8. Отворете локалния адрес, показан в терминала.

## База данни

Приложението използва Entity Framework Core за работа с Microsoft SQL Server. Структурата на базата данни се управлява чрез миграции.

Преди първото стартиране трябва да бъде конфигурирана валидна връзка към SQL Server и да бъдат приложени миграциите. Уверете се, че SQL Server е стартиран и че потребителят има необходимите права за достъп.

Не публикувайте пароли или други чувствителни данни за връзката към базата данни в публичното хранилище.
